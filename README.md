# 🌱 Plant Disease Detector

An AI-powered web app that detects plant diseases from leaf images.
Upload a leaf photo and it will tell you the disease name with confidence %.

Built with Deep Learning + Streamlit.

## ✨ Features
- Detects **38 Plant Diseases** - Tomato, Potato, Apple, Corn, Grape & more
- **93.89% Accuracy** on test data
- Upload JPG / PNG / WEBP image
- Shows Prediction + Confidence %
- Healthy vs Diseased detection

## 🧠 Model Details
- **Base Model:** MobileNetV2 (Transfer Learning)
- **Input Size:** 128 x 128 x 3 (RGB)
- **Dataset:** PlantVillage Dataset - 43,456 images
- **Training:** 5 Epochs
- **Train Accuracy:** 93.89%

## 🛠️ Tech Stack
- Python
- TensorFlow / Keras
- Streamlit
- NumPy, Pillow
